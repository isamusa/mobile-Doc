# 🏥 Mobile Doc: AI-Powered Personal Health Assistant

> **Built for the Google Med-Gemma Impact Challenge**

**Mobile Doc** is a telemedicine application designed for the Nigerian context. It bridges the gap between patients and healthcare by providing an AI-driven "first response" system that can triage symptoms, analyze medical images (lab results/diet), and draft treatment plans for doctor review.

## 🚀 Key Features

* **🧠 Context-Aware AI Chat:** Unlike standard chatbots, Mobile Doc maintains a persistent medical context (`PatientDataService`) that is injected into every prompt. The AI "remembers" your previous ailments when discussing new symptoms.
* **👁️ Smart Vision Analysis:**
* **Lab Results Scanner:** Upload a photo of a paper lab result. The AI analyzes it and explains the values in simple terms.
* **Diet Scanner:** Snap a photo of your meal. The AI identifies the food and offers nutritional advice based on your health profile.


* **⚡ Auto-Triage System:** The app parses AI responses to automatically detect and log:
* **Diagnoses** (e.g., "Malaria likely")
* **Prescriptions** (Drafted for review)
* **Suggested Tests** (Auto-detects "MP", "Widal", "FBC").



## 🛠️ Technical Architecture

### The Stack

* **Frontend:** Flutter (Dart) - Cross-platform mobile UI.
* **Backend:** Firebase (Authentication & Real-time Database).
* **AI Engine:** Kaggle Notebooks hosted via Ngrok.
* **Chat Model:** Gemma 2 2B (Optimized for medical dialogue).
* **Vision Model:** Med-Gemma 4B (Fine-tuned for medical imaging).



### How It Works (The "Secret Sauce")

1. **User Input:** The user types a symptom or uploads an image in the Flutter app.
2. **Context Injection:** The `ApiService` fetches the user's entire medical history string and prepends it to the prompt: `[SYSTEM CONTEXT: Patient has history of Ulcer...] \n USER SAYS: My stomach hurts`.
3. **Kaggle Inference:** The request is sent via **Ngrok** to a running Kaggle kernel where the Gemma models generate a response.
4. **Structured Parsing:** The app receives the text and uses Regex to extract action items. For example, if the AI says *"Prescription: Amartem"*, the app extracts "Amartem" and saves it to the `prescriptions` database.

## 📦 Installation & Setup

1. **Clone the Repo:**
```bash
git clone https://github.com/isamusa/mobile-doc.git
cd mobile-doc

```


2. **Install Dependencies:**
```bash
flutter pub get

```


3. **Configure API Endpoint:**
* Open `lib/services/api_service.dart`.
* Update the `_baseUrl` variable with your active Ngrok/Kaggle URL:
```dart
static const String _baseUrl = 'https://your-ngrok-url.app';

```




4. **Run the App:**
```bash
flutter run

```
